# Security

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub's private vulnerability reporting](https://github.com/CodeWithMoin/gharsaathi/security/advisories/new) and include:

- the affected component and version or commit
- steps to reproduce
- the impact you observed
- any suggested mitigation

Reports involving order placement, authentication, provider credentials, payment state, or personal delivery data receive the highest priority.

## Supported version

Security fixes are applied to the latest version on `main`. This project does not currently maintain older release branches.

Never include real API keys, OAuth tokens, passwords, OTPs, payment credentials, addresses, or user data in a report.
