# GharSaathi demo video

Video: **[Watch the GharSaathi live demo on Loom](https://www.loom.com/share/ce3eb455ab484b059d11ee0382ed2d65)**

- Length: ~4 minutes
- App URL: `http://localhost:3003`
- Order safety shown: the user must tap the bound order card; demo mode never places a real order
- Shot list and voice-over: [docs/VIDEO_SCRIPT.md](docs/VIDEO_SCRIPT.md)

## What it shows

1. Address-first header with linked Zepto / Swiggy Instamart accounts
2. Household memory recall ("Mujhe kya pasand hai?")
3. One-sentence express order → bound order card → tap-only **Place order**
4. Price comparison across stores
5. Shopping from a photo of a pack
6. Tracking card with ETA and Delivery line ready
7. Sarvam delivery line guiding a rider, rider-call card in app
8. Settings drawer
9. Safety: orders only on tap, cash on delivery, never OTPs or passwords
